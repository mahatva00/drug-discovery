# 💊 Molecular Drug Discovery — GNN-VAE

> An AI pipeline that takes a known drug name, learns its molecular structure, and generates novel drug-like candidates using a Graph Neural Network + Variational Autoencoder trained on 250,000 real molecules.

---

## 🧠 What This Project Does

Most drug discovery takes years and costs billions. This project demonstrates a deep learning approach to **de novo molecule generation** — given a drug like Aspirin or Ibuprofen, the model finds chemically similar, novel molecules that could work as alternatives or derivatives.

**Input:** A drug name (e.g. `"Tamoxifen"`)  
**Output:** Top 3 novel drug-like candidate molecules with structures and property scores, saved as a PNG

---

## ✨ Key Features

- **GNN Encoder** — treats molecules as graphs (atoms = nodes, bonds = edges) and encodes them using Graph Isomorphism Network (GIN) convolutions
- **Variational Autoencoder** — learns a continuous latent space of molecular properties; new molecules are generated by sampling near a known drug's position
- **PubChem Integration** — automatically fetches the structure of any drug by name via the PubChem REST API
- **Lipinski Filtering** — filters generated candidates using Lipinski's Rule of Five (logP, QED, synthetic accessibility)
- **ZINC250k Matching** — matches generated property vectors to the nearest real molecules from the 250,000-molecule ZINC dataset
- **Visual Output** — renders molecular structures side-by-side as a clean PNG with chemical formulas and property scores
- **KL Annealing** — stabilizes VAE training by gradually increasing the KL divergence weight over 15 epochs
- **Crash Protection** — saves mid-training checkpoints every 5 epochs so training can be resumed

### 1. Clone the repository

```bash
git clone https://github.com/mahatva00/drug-discovery.git
cd drug-discovery
```

### 2. Create and activate a virtual environment

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Mac/Linux
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

> PyTorch Geometric requires matching versions of torch-scatter, torch-sparse, and torch-cluster. If you run into issues, refer to the [official PyG installation guide](https://pytorch-geometric.readthedocs.io/en/latest/install/installation.html).

The ZINC250k dataset is not included in this repo due to size. Download it from Kaggle:

👉 [ZINC250k on Kaggle](https://www.kaggle.com/datasets/basu369victor/zinc250k)

Place the CSV file at:
```
data/zinc_raw/raw/zinc250k.csv
```

## 🏃 Running the Project

### Train the model

```bash
python train.py
```

This trains for 50 epochs on all 250,000 ZINC molecules. Saves:
- `checkpoints/best_model.pt` — best model by validation loss
- `checkpoints/mid_checkpoint_epochXX.pt` — every 5 epochs
- `checkpoints/loss_history.csv` — full loss log

GPU is used automatically if available (strongly recommended).

### Generate drug candidates

```bash
# Interactive mode
python main.py

# With arguments
python main.py --drug "Aspirin" --samples 2000 --top 3 --noise 0.5
```

**Arguments:**

| Argument | Default | Description |
|---|---|---|
| `--drug` | (prompted) | Name of the input drug |
| `--samples` | 2000 | Latent samples to generate |
| `--top` | 3 | Number of candidates to output |
| `--noise` | 0.5 | Exploration radius — 0.3=similar, 1.0=diverse |

Output PNG is saved to `visualizations/drug_candidates_<drugname>.png`.

### Visualize training results

```bash
python visualize.py
```

Generates plots for molecule grids, t-SNE of the latent space, training curves, and property distributions.

## 🔬 How It Works

### 1. Drug lookup
The drug name is sent to PubChem's API which returns the molecule's SMILES string — a text representation of its chemical structure.

### 2. Molecule → Graph
The SMILES is converted to a molecular graph using RDKit. Each atom becomes a node with 14 features (atomic number, charge, valence, etc.) and each bond becomes an edge with 5 features.

### 3. GNN Encoding
The graph is passed through 3 layers of GIN convolutions, which aggregate information from neighbouring atoms. Global mean pooling produces a single vector for the whole molecule. Two linear layers project this into `mu` and `log_var` — the parameters of a probability distribution in latent space.

### 4. Latent Space Sampling
New molecules are generated by sampling random points **near** the input drug's position (`mu`) in latent space, controlled by the `--noise` parameter. Smaller noise = more similar molecules; larger noise = more diverse.

### 5. Decoding
Each sampled latent vector is passed through an MLP decoder that predicts three molecular properties: **logP** (lipophilicity), **QED** (drug-likeness score), and **SAS** (synthetic accessibility score).

### 6. Lipinski Filter
Candidates are filtered for drug-likeness:
- logP between -2.0 and 5.0
- QED ≥ 0.5
- SAS ≤ 6.0

### 7. ZINC Matching
Passing candidates are matched to the nearest real molecule in ZINC250k by Euclidean distance in property space. This guarantees the output molecules actually exist and are synthesizable.

### 8. PNG Output
The input drug and top candidates are rendered side-by-side with their 2D structures, chemical formulas, and property scores.

## 📊 Sample Output

| Property | Meaning | Ideal Range |
|---|---|---|
| **logP** | Lipophilicity (how well it crosses membranes) | -2.0 to 5.0 |
| **QED** | Drug-likeness score | > 0.5 (max 1.0) |
| **SAS** | Synthetic accessibility (ease of synthesis) | < 6.0 (lower = easier) |
| **Dist** | Property distance to matched ZINC molecule | Lower = closer match |
